# Astronic Tabletop

### Sua mesa de RPG, sem limites para a imaginação.

Astronic Tabletop é uma plataforma virtual desenvolvida para proporcionar uma experiência interativa de RPG de mesa, conectando mestres e jogadores em um ambiente compartilhado.

A plataforma oferece ao mestre ferramentas para preparar, organizar e conduzir suas sessões, enquanto os jogadores acompanham os acontecimentos e interagem com os elementos disponibilizados durante a aventura.

Mais do que reproduzir uma mesa física em formato digital, o Astronic Tabletop busca oferecer liberdade para construir experiências próprias, adaptar diferentes sistemas de RPG e transformar cada sessão em uma experiência única.

---

## Funcionalidades

### Sessões multiplayer
- Criação e gerenciamento de sessões de RPG.
- Entrada de jogadores por códigos de acesso.
- Ambientes compartilhados entre mestre e participantes.
- Sincronização de informações em tempo real.
- Controle de acesso e permissões de participantes.

### Mesa virtual
- Apresentação e gerenciamento de mapas.
- Inserção e organização de marcadores interativos.
- Disponibilização de pontos de interesse para os jogadores.
- Interação dos participantes com os elementos liberados pelo mestre.
- Controle privado do ambiente durante a preparação e condução da sessão.

### NPCs e informações
- Criação e gerenciamento de NPCs.
- Controle de visibilidade dos personagens apresentados aos jogadores.
- Disponibilização de informações e conteúdos durante a sessão.
- Sistema de handouts para compartilhar materiais com os participantes.

### Biblioteca de mídias
- Organização de imagens e GIFs.
- Armazenamento e utilização de documentos.
- Compartilhamento de mídias durante as sessões.
- Transmissão de conteúdo audiovisual entre participantes.

### Áudio sincronizado
- Reprodução de áudio compartilhado entre os participantes.
- Sincronização da experiência sonora durante as sessões.
- Utilização de música e efeitos sonoros para ambientação.

---

## Uma experiência para mestres e jogadores

**Para o mestre:** controle sobre o ambiente da sessão, preparação de cenários, gerenciamento de NPCs e liberdade para apresentar informações no momento desejado.

**Para os jogadores:** um espaço compartilhado para acompanhar a aventura, visualizar os conteúdos disponibilizados e interagir com os elementos apresentados pelo mestre.

Cada participante possui seu próprio acesso à sessão, enquanto as informações compartilhadas são sincronizadas para manter todos conectados à mesma experiência.

## Tecnologias

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura da plataforma |
| CSS3 | Interface e estilização |
| JavaScript | Lógica e interatividade |
| Vite | Desenvolvimento e build |
| Firebase Authentication | Autenticação de usuários |
| Firebase Realtime Database | Sincronização e persistência de dados |
| WebRTC | Comunicação e transmissão de mídias |

## Propósito

O Astronic Tabletop nasceu da vontade de tornar as sessões de RPG mais acessíveis, organizadas e interativas, sem limitar a criatividade de quem está contando uma história.

Independentemente do sistema utilizado, cada mestre pode construir seu próprio ambiente de jogo e conduzir suas aventuras, enquanto os jogadores participam de uma experiência compartilhada.
